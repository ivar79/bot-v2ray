# راهنمای استفاده از ربات Forwardv2raybot

## ۱. پیدا کردن و باز کردن ربات

۱. تلگرام را باز کنید.
۲. در نوار جستجوی بالا بنویسید: **Forwardv2raybot**
۳. روی نام ربات در لیست نتایج ضربه بزنید.
۴. دکمه **Start** یا **شروع** را در پایین صفحه بزنید.

---

## ۲. شروع استفاده

بعد از زدن دکمه Start، ربات یک پیام خوش‌آمدگویی نشان می‌دهد و لیست دستورات در دسترس را می‌توانید با ارسال `/help` ببینید.

برای دیدن پیام خوش‌آمدگویی:
```
/start
```

برای دیدن لیست همه دستورات:
```
/help
```

> **نکته مهم:** این ربات فقط برای مدیران مجاز است. اگر شما در لیست مدیران نباشید، ربات پیام «دسترسی غیرمجاز» نشان می‌دهد.

---

## ۳. توضیح هر دستور

### دستورات عمومی

| دستور | توضیح |
|-------|-------|
| `/start` | پیام خوش‌آمدگویی و معرفی ربات |
| `/help` | نمایش لیست همه دستورات موجود |
| `/status` | نمایش وضعیت سیستم (تعداد تنظیمات، منابع و...) |

---

### دستورات بارگذاری تنظیمات

| دستور | توضیح |
|-------|-------|
| `/upload` | شروع فرایند ارسال تنظیمات V2Ray |
| `/cancel` | لغو فرایند بارگذاری در حال انجام |

**نحوه استفاده از /upload:**
۱. دستور `/upload` را بفرستید.
۲. ربات از شما می‌خواهد تنظیمات را به صورت **متن** یا **فایل .txt** ارسال کنید.
۳. بعد از ارسال، ربات از شما می‌خواهد **اپراتور** (ارائه‌دهنده) را انتخاب کنید.

**پروتکل‌های پشتیبانی‌شده:** vmess, vless, trojan, ss, hysteria2, hy2, hysteria

---

### دستورات مدیریت منابع

| دستور | توضیح |
|-------|-------|
| `/addsource` | اضافه کردن یک کانال تلگرامی به عنوان منبع معتبر |
| `/removesource` | حذف یک منبع |
| `/sources` | نمایش لیست منابع معتبر |

**نحوه استفاده از /addsource:**
```
/addsource -1001234567890 نام_کانال @نام_کاربری
```
- عدد اول: شناسه عددی کانال تلگرام
- نام کانال و نام کاربری اختیاری هستند

---

### دستورات خروجی و انتشار

| دستور | توضیح |
|-------|-------|
| `/generate` | تولید فایل‌های خروجی از تنظیمات ذخیره‌شده |
| `/publish` | انتشار فایل‌ها در گیت‌هاب و کانال تلگرام |
| `/send` | ارسال مستقیم فایل‌ها یا کانفیگ‌ها به کانال خروجی |

**نحوه استفاده:**
۱. ابتدا `/generate` بفرستید تا فایل‌ها تولید شوند.
۲. سپس `/publish` بفرستید تا فایل‌ها منتشر شوند.

**نحوه استفاده از /send:**
```
/send            → نمایش منوی انتخاب
/send files      → ارسال فایل‌های خروجی (همه، به تفکیک پروتکل و اپراتور)
/send recent     → ارسال ۱۰ کانفیگ اخیر به صورت کارت
/send all        → ارسال همه کانفیگ‌های فعال به صورت کارت
```

> **نکته:** بعد از هر دریافت خودکار (fetch)، کانفیگ‌های جدید به صورت خودکار به کانال خروجی ارسال می‌شوند.

---

### دستورات اشتراک (Subscription)

| دستور | توضیح |
|-------|-------|
| `/addsub` | اضافه کردن یک لینک اشتراک (Subscription) به عنوان منبع |
| `/listsub` | نمایش لیست اشتراک‌ها و وضعیت آن‌ها |
| `/fetch` | دریافت فوری همه اشتراک‌های فعال |
| `/autofetch` | روشن/خاموش کردن دریافت خودکار و تنظیم فاصله زمانی |

**نحوه استفاده از /addsub:**
```
/addsub https://example.com/sub.txt نام_دلخواه
```
- لینک اشتراک را می‌توانید بدون آرگومان هم بفرستید؛ ربات به صورت گفتگو از شما می‌خواهد.
- دریافت خودکار برای اشتراک جدید به صورت پیش‌فرض فعال است.

**نحوه استفاده از /fetch:**
```
/fetch
```
- همه اشتراک‌های فعال را دریافت می‌کند و نتیجه (موفق/ناموفق) را گزارش می‌دهد.
- کانفیگ‌های جدید به صورت خودکار به کانال خروجی ارسال می‌شوند.

**نحوه استفاده از /autofetch:**
```
/autofetch               → نمایش وضعیت فعلی
/autofetch on            → فعال کردن دریافت خودکار
/autofetch off           → غیرفعال کردن دریافت خودکار
/autofetch interval 12   → دریافت هر ۱۲ ساعت (بین ۱ تا ۱۶۸ ساعت)
```

**حذف اشتراک:** با `/listsub` لیست اشتراک‌ها نمایش داده می‌شود؛ روی دکمه 🗑 هر اشتراک بزنید تا حذف شود.

---

### دستورات منو و قالب‌بندی

| دستور | توضیح |
|-------|-------|
| `/menu` | نمایش منوی دکمه‌ای برای کار راحت‌تر از موبایل |
| `/setremark` | تنظیم قالب نام (remark) کانفیگ‌های خروجی |
| `/setwelcome` | تنظیم پیام خوش‌آمد |

**نحوه استفاده از /setremark:**
```
/setremark {flag} {country} {protocol}
```
- متغیرهای قابل استفاده: `{location}` `{flag}` `{country}` `{protocol}`
- بدون آرگومان، ربات به صورت گفتگو قالب را از شما می‌پرسد.
- این قالب روی نام کانفیگ‌هایی که به کانال خروجی ارسال می‌شوند اعمال می‌گردد.

**نحوه استفاده از /setwelcome:**
```
/setwelcome به کانال ما خوش آمدید {name}!
```
- متغیرهای قابل استفاده: `{name}` `{group}`

---

### دستورات تنظیمات

| دستور | توضیح |
|-------|-------|
| `/setgithub` | تنظیم مخزن گیت‌هاب برای انتشار |
| `/setoutput` | تنظیم کانال تلگرامی خروجی |

**نحوه استفاده از /setgithub:**
```
/setgithub myuser v2ray-configs main
```
- نام کاربری گیت‌هاب
- نام مخزن
- نام شاخه (اختیاری، پیش‌فرض: main)

**نحوه استفاده از /setoutput:**
```
/setoutput -1001234567890
```
- شناسه عددی کانال تلگرامی که فایل‌ها به آن ارسال می‌شوند

## ۴. جریان کاری عادی

### مثال ۱: بارگذاری تنظیمات

```
شما: /upload
ربات: 📥 تنظیمات V2Ray را ارسال کنید...

شما: [متن تنظیمات یا فایل .txt]
ربات: اپراتور را انتخاب کنید [دکمه‌های انتخاب]

شما: [اپراتور را انتخاب می‌کنید]
ربات: ✅ تنظیمات با موفقیت ذخیره شد
```

### مثال ۲: انتشار خروجی

```
شما: /generate
ربات: 📤 خروجی تولید شد
       تعداد فایل‌ها: ۵
       حجم کل: ۱۲.۳ KB

شما: /publish
ربات: 🚀 در حال انتشار...
       ✅ گیت‌هاب: با موفقیت منتشر شد
       ✅ تلگرام: ۵ فایل ارسال شد
```

### مثال ۳: مشاهده وضعیت

```
شما: /status
ربات: 📊 وضعیت سیستم
       تنظیمات: ۱۵۰
       منابع: ۳
       دسته‌ها: ۱۲
```

## ۵. قابلیت‌های مدیر

فقط مدیران مجاز می‌توانند از ربات استفاده کنند. مدیران می‌توانند:

- **تنظیمات بارگذاری کنند:** با استفاده از `/upload` تنظیمات V2Ray ارسال کنند
- **منابع مدیریت کنند:** کانال‌های تلگرامی معتبر اضافه یا حذف کنند
- **اشتراک‌ها را مدیریت کنند:** لینک اشتراک اضافه کنند (`/addsub`)، لیست ببینند (`/listsub`) و دریافت خودکار را تنظیم کنند (`/autofetch`)
- **خروجی تولید و منتشر کنند:** فایل‌ها را تولید و در گیت‌هاب یا کانال تلگرام منتشر کنند (`/generate`، `/publish`، `/send`)
- **وضعیت سیستم را ببینند:** با `/status` اطلاعات سیستم را مشاهده کنند
- **تنظیمات را تغییر دهند:** مخزن گیت‌هاب، کانال خروجی، قالب نام کانفیگ‌ها و پیام خوش‌آمد را تنظیم کنند

> **نکته:** اگر کسی که مدیر نیست از ربات استفاده کند، پیام «دسترسی غیرمجاز» دریافت می‌کند.

---

## ۶. مشکلات رایج و راه‌حل‌ها

### ❌ ربات جواب نمی‌دهد

**علت محتمل:** شما در لیست مدیران نیستید.
**راه‌حل:** با مدیر اصلی تماس بگیرید تا شناسه تلگرام شما را به لیست مدیران اضافه کند.

---

### ❌ پیام «دسترسی غیرمجاز» دریافت می‌کنید

**علت:** شناسه تلگرام شما در سیستم ثبت نشده است.
**راه‌حل:** از مدیر اصلی بخواهید شناسه عددی تلگرام شما را به سیستم اضافه کند.

---

### ❌ دستور اشتباه فرستادم

**راه‌حل:** هیچ اتفاقی نمی‌افتد. ربات یک پیام راهنما نشان می‌دهد. دوباره دستور صحیح را بفرستید.

---

### ❌ اتصال تلگرام مشکل دارد

**علت:** مشکل اینترنت یا سرور تلگرام.
**راه‌حل:**
۱. اتصال اینترنت خود را بررسی کنید.
۲. چند لحظه صبر کنید و دوباره امتحان کنید.
۳. اگر مشکل ادامه داشت، بعداً دوباره تلاش کنید.

---

### ❌ ربات کند پاسخ می‌دهد

**علت:** پردازش تنظیمات ممکن است کمی طول بکشد.
**راه‌حل:** صبور باشید. اگر بیش از یک دقیقه طول کشید، دوباره امتحان کنید.
